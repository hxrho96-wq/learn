# learn

我想學：培養視覺創意與靈感，把日常觀察、文字或情緒轉化成海報概念。

我以前卡在：常常想不到主題，花費許多時間在尋找靈感或想法。

我現在的程度，以及我怎麼測的：偶爾能想到一個點子，但不容易持續產出。可以測試自己是否能在 10 分鐘內，針對同一個主題提出 5 個不同方向。

5 週後我要做到：每天提出至少 5 個海報概念，並完成其中 1 張；即使面對陌生主題，也能從文字、物件、情緒或生活觀察中找到創作方向。

我練習的場景、時間和每週次數：每天固定 30–45 分鐘，每週 5 天。前 10 分鐘發想，接著選一個點子用 Illustrator 完成。

那個時候我有空的感官：觀察身邊的顏色、形狀、材質、文字、聲音和情緒，把它們轉換成視覺元素。

我的產品會怎麼幫我：每天提供一個刺激，例如一個詞、一張圖片、一種情緒或兩個無關的物件，要求我產生多個不同聯想。產品也會保存我的靈感、提醒我不要太早評判，並把每天的作品整理成「靈感成長紀錄」。
